# atlas-sync

Метод — `../../references/atlas-method.md`: §4 карточки, §5 трассы, §7 globs, §9 свежесть, §10 проверки.

## Шаги

1. **База.** Собрать `synced` всех карточек (Grep `^synced:` в `.claude/rules/atlas/`). Базовая точка — самый старый.
2. **Изменения.** `git diff --name-status <база>..HEAD` и `git status --porcelain`; незакоммиченное помечать отдельно.
3. **Владельцы.** Сопоставить изменённые файлы с карточками по globs (Glob). Отдельно — файлы без владельца
   и файлы с двумя владельцами.
4. **Карточки.** Для каждой затронутой: `git diff <synced>..HEAD -U0 -- <её globs>` и критерии метода §9:
   - не устарела → `synced` = HEAD, текст не трогать;
   - устарела → прочитать изменённый код → минимальная правка нужных разделов → `synced` = HEAD.
     Добавил ловушку — проверь, нельзя ли убрать закрытую кодом (P9).
5. **Трассы.** Для каждой трассы Grep якорей её шагов (C4). Сломанный шаг → проследить заново только этот участок.
6. **L0.** Править, только если изменились модули, процессы, пути данных, env, рецепты или омонимы. Бюджет ≤ 150 строк и ≤ 14 000 символов.
7. **Файлы без владельца.** Предложить владельца; при неоднозначности — AskUserQuestion. Пересечения globs — отдать
   файл более точному glob, у второй карточки сузить.
8. **Проверки** C1–C6 на затронутом.
9. **Отчёт** — таблица: карточка · статус (свежая / сдвинут synced / исправлена) · что изменено · размер;
   файлы без владельца; нарушения проверок.

## Политика моделей
Сбор диффов и списков — Sonnet. Решение «устарела ли» и правки карточек/трасс — основная модель
(при большом диффе — параллельные субагенты без model-override, по карточке на субагента).

## Границы
Незатронутые модули не читать. Код не править. Коммиты — только по команде владельца.
