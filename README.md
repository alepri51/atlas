# atlas — лёгкий слой понимания проекта для агентов

Наследник GRACE без XML, без разметки в коде и без процессного слоя. Агент быстрее понимает «что, где и как работает»:
- **L0 `AGENTS.md`** — карта: процессы и режимы, модули, карта данных, раскатка, сквозные правила, омонимы; грузится сама через `@AGENTS.md` в CLAUDE.md.
- **Карточки `.claude/rules/atlas/M-*.md`** — инварианты и грабли, «что ещё менять вместе», побочки, проверка; Claude Code подмешивает карточку, когда агент читает файл модуля (`paths:`).
- **Трассы `docs/atlas/F-*.md`** — сквозные сценарии `путь:символ` с процессами и режимами.
- **`atlas-scout`** — поисковый субагент (Sonnet), который, в отличие от встроенного Explore, получает CLAUDE.md и карту.

Замер на AI.UI (3 раунда, слепая оценка, скрытые наборы вопросов): «как работает» — в 15–23 раза меньше токенов и вызовов;
«что затронет» — полнота 7.4 → 9.2 из 10; планы изменений — 7.0 → 8.6; галлюцинаций в 2–8 раз меньше; стоимость −11…−18%.
Подробно — `references/EVAL-AI-UI-2026-09-24.md`, обоснование — `references/RATIONALE.md`, метод — `references/atlas-method.md`.

## Установка в выбранный репозиторий
В Claude Code из каталога нужного репозитория:
```
/plugin marketplace add C:\projects\AI_AGENTS\SKILLS\atlas
/plugin install atlas@atlas --scope local
```
или из терминала в каталоге репозитория:
```
claude plugin marketplace add C:\projects\AI_AGENTS\SKILLS\atlas
claude plugin install atlas@atlas --scope local
```
Из GitHub (приватный репозиторий, нужен доступ): `claude plugin marketplace add alepri51/atlas`, затем та же команда install.

`--scope local` — плагин включён только в этом репозитории и только у вас; `--scope project` — для всей команды через
настройки репозитория.

## Использование (только по команде — скиллы не вызываются моделью сами)
- `/atlas:atlas-init` — построить слой: разведка → нарезка модулей (гейт одобрения) → карточки → трассы → `AGENTS.md` →
  строки CLAUDE.md и `.claude/agents/atlas-scout.md` (в пределах одобренного) → проверки C1–C6 → проверка доставки.
- `/atlas:atlas-sync` — догнать слой до текущего кода по `git diff` от `synced` карточек.

Исходный код проекта скиллы не меняют. Файлы слоя остаются в репозитории и работают без плагина: плагин нужен только
чтобы строить и обновлять слой.
